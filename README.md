# Crystal Launcher

Native Android launcher prototype built with Kotlin and Jetpack Compose.

## Included
- Home screen with date and clock
- Installed-app discovery and launch
- App search and app grid
- Light and dark themes
- Translucent glass-inspired panels
- Android Home-app intent filter

## Build
Open this project in Android Studio, sync Gradle, and run on an Android device.
Minimum SDK: Android 8.0 (API 26).

## Status
Initial playable launcher prototype. Background blur, widget placement, icon packs, wallpaper picker, and advanced customization are planned for future versions.
